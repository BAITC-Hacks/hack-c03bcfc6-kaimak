        04 / СРАВНЕНИЕ СТРАТЕГИЙ

        ОТКРЫТАЯ МЕТОДОЛОГИЯИз чего складывается результат?+

        Источник: task/Датасет районов.docx. Учебные показатели, а не официальный прогноз. Для правил выбора мер используется подробный датасет: ровно 5 решений, максимум 2 из одного направления.

        Score = 0.7 × Davg + 0.3 × Dmin − Ncrit

        D — сумма 10 показателей с весами из датасета. Davg учитывает доли населения, Dmin — слабейший район. Ncrit — число значений строго ниже 40. Показатели ограничиваются диапазоном 0–100 после суммирования всех эффектов и синергий. Промежуточные вычисления не округляются.

        Синергии

        M1 + M2 → T1 +2
        M10 + M12 → B1 +2
        M5 + M6 → E2 +2

        Фиксированный бонус в районе первой меры пары, без масштабирования лагом.

        Конфликты

        M1 / M3 — в любых районах.
        M4 / M7 — в одном районе.
        M5 / M13 — в одном районе.
